Comfort is half the question; the other half is whether the decoder still sees the SSVEP. A lower depth gives a weaker response, so measure accuracy at each depth with the headset before lowering any config's default.

  1. Record one cued session per depth, same config and same sitting. Change the order between people so fatigue doesn't always land on the same depth. 
    OUT=~/brainsync-depth-ab
.venv/bin/python -m brainsync.record -c two_targets --depth 1.0 --save-dir "$OUT/d1.0"
.venv/bin/python -m brainsync.record -c two_targets --depth 0.6 --save-dir "$OUT/d0.6"
.venv/bin/python -m brainsync.record -c two_targets --depth 0.4 --save-dir "$OUT/d0.4"
  2. Score each depth's sessions and compare the accuracies. 
    for d in 1.0 0.6 0.4; do
  echo "depth $d"; .venv/bin/python -m brainsync.score_cued "$OUT/d$d"/*_cued.npz
done
  3. To include the square wave, copy brainsync/stimulus/configs/two_targets.toml, set waveform = "square" under [stimulus], and pass the copy with -c path/to/copy.toml. At 60 Hz, 17 Hz is 3.53 frames per cycle, so its square duty cycle is uneven; the config check warns about it.
  4. Ask for a comfort rating (1–5) after each session, the same scale as the blind test, so comfort and accuracy line up per depth.
  5. For BrainChess, repeat with -c chess_probe: its board-square targets are small and give the weakest response, so a lower depth costs the most there.

Flickering light

This page flickers squares between dark and light. Flicker at 15–25 Hz is the band most likely to trigger a seizure in people with photosensitive epilepsy. Don't continue if you or anyone watching has epilepsy or has had a seizure.

Press Esc at any time to stop the flicker.
