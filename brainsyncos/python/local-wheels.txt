# Wheels built locally (not from PyPI) that go into the BrainSync runtime venv
# (/opt/brainsyncos/venv, package brainsync-runtime), one distribution name per
# line, e.g.
#   brainflow
# for the Cerelog BrainFlow fork built for linux-aarch64 (Phase 3c).
#
# For each name listed here, scripts/venv.sh needs exactly one wheel of it in
# build/wheels/local/ (put there by the step that builds it, before
# scripts/build.sh packages) and fails without it; wheels there that are not
# listed are refused. They are installed with --no-deps after the locked
# wheels, so their own dependencies must already be in brainsync.lock.txt.
# Their sha256 is recorded in /usr/share/doc/brainsync-runtime/wheels.txt.
